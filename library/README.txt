THƯ VIỆN ÂM THANH (không bắt buộc)

Tool có sẵn nhạc nền và hiệu ứng tự tạo (không lo bản quyền). Muốn dùng file của bạn:
- Nhạc nền:   library\music\light\       (vui nhẹ, mặc định)
              library\music\thoughtful\  (trầm, suy nghĩ)
  Bỏ 1 file .mp3/.wav vào thư mục, tool dùng file đầu tiên (theo tên) và lặp lại cho đủ dài.
- Hiệu ứng:   library\sfx\pop.wav, coin.wav, ding.wav, whoosh.wav, tick.wav, thud.wav, cash.wav

Chỉ dùng nhạc có giấy phép rõ ràng: YouTube Audio Library, Pixabay Music...
