Bàn tay cầm bút trong đoạn Ben's Notebook
=========================================

Nguồn: "Edit Hand Holding Pencil" của darrenbeck trên Openclipart
https://openclipart.org/detail/172946/edit-hand-holding-pencil
Giấy phép: Public Domain / CC0 1.0 (Openclipart: mọi hình đều là public domain).
Dùng thương mại được, không cần ghi nguồn.

- openclipart_172946_hand_holding_pencil.svg : file gốc.
- ../hand_pencil.png   : bản nét đen trắng (giống kiểu whiteboard) - tool đang dùng.
- hand_pencil_color.png: bản màu gốc.

Đổi tay khác: chép một ảnh PNG nền trong suốt, ngòi bút quay sang TRÁI, đặt tên
assets/hand_custom.png. Tool tự tìm đầu ngòi bút (điểm xa nhất bên trái) và dùng ảnh đó.
Ví dụ muốn dùng bản màu: chép hand_pencil_color.png thành ../hand_custom.png.
